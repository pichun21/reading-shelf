跨裝置同步

把書房存到你 GitHub 上的私人儲存庫，手機和電腦都連上同一個，就會自動保持一致。

第一次設定：建立儲存庫和權杖（約 5 分鐘）
  1. 到 GitHub 新增儲存庫，名稱填 reading-shelf-data，選 Private，勾選「Add a README file」，按 Create repository。
  2. 到 建立 Fine-grained 權杖：名稱隨意，到期日依需要設定。
  3. 「Repository access」選 Only select repositories，只勾 reading-shelf-data。
  4. 「Permissions」裡的 Contents 設為 Read and write，其他不用動，按 Generate token。
  5. 複製產生的權杖（github_pat_ 開頭），貼到下面。每台裝置都貼同一組即可。

權杖只存在這台裝置的瀏覽器裡。它只能存取你指定的那一個儲存庫；不用時可以隨時到 GitHub 刪掉。
