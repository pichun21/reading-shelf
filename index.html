保存與同步

登入後，書會存到雲端。換瀏覽器、換手機，登入同一個帳號就會回來。

  • 書和封面會存在你自己的 Google 雲端硬碟裡一個 App 專用的隱藏資料夾，只有頁間日子讀得到，不會佔用或動到你其他的檔案。
  • 不登入也能照常使用，書只會存在這個瀏覽器裡。
進階：改用 GitHub 私人儲存庫同步
  1. 到 GitHub 新增儲存庫，名稱填 reading-shelf-data，選 Private，勾選「Add a README file」。
  2. 到 建立 Fine-grained 權杖，「Repository access」只選這個儲存庫，「Contents」設為 Read and write。
  3. 把權杖（github_pat_ 開頭）貼到下面。

匯出備份

書房的資料只存在這台裝置的瀏覽器裡，定期匯出一份比較安心。

匯入資料

可以匯入 Excel 書單，或之前匯出的 JSON 備份。

Excel 書單的格式
  1. 第一列放欄位名稱，至少要有「書名」「年份」「月份」。
  2. 可以再加「作者」「譯者」「標籤」「喜歡」「閱讀筆記」。「喜歡」填「是」，或把書名那格塗上底色都可以。
  3. 封面圖可以直接貼在 Excel 裡同一列的格子上。
  4. 如果每個年份分一個工作表，工作表名稱寫年份（例如 2025），就可以不用「年份」欄。

匯入前會先顯示預覽，可以選擇合併或取代目前的書房。
